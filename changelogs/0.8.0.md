# Changelog 0.8.0:
##### Mods:
- Update to Neoforge 21.1.248
- Update mods (except a few, but mostly an upgrade to previous versions)
- Added more mods, some of them are Refined Storage (and its addons), Draconic Evolution and more importantly, or not, Logistical Networks :p (and some more magic like Neo Vitae and Malum or Silent Gear)
- Removed some mods, like Quest spliter or Kubejs Mekanism, since these are not needed anymore

# Changes:
##### Important ones:
- Now we have EMI and JEI, this is a client side, you can choose whatever you want
- There has been a ton of unification with Eternal Ores, like Certus or Fluix or Modularium, these has recipes to convert from one to another
- Minings dimensions from Just Another Mining Dimension mod will be deleted on 0.9, Eternal Ores has a mining dimension now
- There is an optional progression now if you want a big task to achieve. For now, there is up to Universium
- Some endgame items are craftable now, they are just crafting ingredients

##### Modular Machinery Reborn:
- More multiblocks! I mean, a lot of them compared to 0.7.2
- Some multiblocks has received some changes to structure, check them out
- Fixes location, before it works only on the overworld, now, in every dimension
- Added IFS compact for the Drill Head
- Adding parallel to a few multiblocks like Arbolertum or Phyto
- Added missing machine component recipes
- Giving an early access to the blueprint
- Added coke block as a recipe on the primitive and the other furnaces
- Reduce recipe cooldown to 1 second and disable replace as this can void blocks
- Hatches and buses has new recipes, it's not just 2 hatches/bus = new one, they are much more complete
- Recipes for the new multiblocks
- Modularium has been changed to EO one, there is a recipe to convert!
- Put energy requirement to last 2 furnaces (they were there, but not shown in recipe, no more hidding stuff)
- Empty crystals has now a independent roll on the Forge. For example, if you have a 255 raw copper to ingot recipe, there will be 255 rolls for the Crystals
- Multiblocks has tooltips to the controller and the controller's GUI detailing more
- Some multiblocks has recipes with more information
- Buff the output of heavy water
- Some multiblocks doesn't need Modularium now! Like Arboletum
- Energy bar has changed
- More saplings to Arboletum
- Correcly give the amount of loot you would get from loot
- Celestial Forge can now do a lot more with ore processing from other mods, check it!

##### Recipes:
- Some recipes has been removed to balance stuff, check your patterns!
- Giving the Tick profiler a recipe
- Fix custom recipes views
- Hide some repeating items, that just change the nbt
- Some of the mysticalagriculture items got a new recipe, so patterns will be invalid
- Nerfed the pattern provider and interface families, aka, using a bit of materials more and 2 steps more. For example, Extended pattern provider has 2 recipes now, one using 1 Mega Pattern or 4 normal ones
- Solar panels has been nerfed in recipe
- Fix cobalt bee recipe
- Added farmingforblockheads farmland recipes, no more right clicking
- AE2 presses has alternative recipes, so you don't need to find a meteour
- Press Mold now uses a wooden shovel instead of any shovel (I don't want you to use a supremium shovel for a clay machine)
- Cloches recipes for MA has been buffed (0.9 will have more changes to them)
- Heavy core and Crying obsidian has crafting table recipes
- Moss family has recipes using MA
- There is an optional WIP stonecutter recipe, this is disabled by default, but you can turn it on easy. Go to your instace/server folder, then kubejs/server_scripts/stonecutter/cuts.js and change the second line from true to false (let disable = false;)
- Prismarine and Sea lantern can be converted back to shards and crystals, 4 each. I know that Sea Lantern will be missing some materials
- Powah reactors and some machines from it has recieved more fuels and coolants!
- Liquid Darkness and Liquid Light has been given a recipe using Create
- Eggs can be obtained with dought using Create
- Andesite alloy has been given some modifications, not with autocrafting from Create since you can't change the output amount
- Coal bee now gives all type of coal from EO
- Crafting stations can now go from slab to full block
- Added an alternative dielectric paste from Powah recipe, you have 3 to choose from
- Changes to Reinforced Glass recipe
- Added radiance and shadow casing from Create
- Create honey is now given and used instead of Productive Bee, since it has a much nicer texture and more uses
- Remove some Xycraft recipes from Mek ore processing in favour of EO ones, since Xycraft has lot less uses
- Crushing Wheels have been given 3 new recipes, one early that costs lots, and another 2 that gives more but needs to use other part of Create to make them
- Spore blosson has a recipe now
- Steel ingot can be obtained using charcoal dust and charcoal using Oritech 


##### Quests:
- Fixes typos
- Fixes nbt issues on some quests that needs NBT like MMR or Combs
- New Quests! From Malum to progression!
- Changes to some quests like Oritech or MMR ones
- Compact with EMI, if you click a task item, it goes to the recipe, and if you press esc, it goes back to quest screen instead of inventory

- Now, you get emergency items, its basically 5.5 armor, a bronze sword and a stone pick, in case you die while standing near the portal
